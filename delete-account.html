데이터 삭제 안내

기기에 있는 기록과 이전 버전에서 서버에 저장한 기록의 삭제 방법은 다릅니다.

이 기기의 기록

직접 작성한 일정·일기 등은 해당 목록이나 수정 화면에서 삭제할 수 있습니다. 기기에 있는 기록을 모두 지우려면 Android 설정 → 애플리케이션 → 가족일정 → 저장공간 → 데이터 삭제를 선택하세요. 브라우저에서는 가족일정 사이트의 저장 데이터를 지우면 됩니다. 캐시 삭제나 로그아웃만으로는 모든 기기 기록이 삭제되지 않습니다.

앱 데이터를 지우면 기기에서 새로 작성한 기록과 이전 공유 기록의 기기 사본이 함께 지워집니다. 기기 사진첩에 따로 남아 있는 원본 사진이나 이전 서버 기록은 이 작업으로 삭제되지 않습니다.

기존 계정과 이전 서버 기록

이전 버전의 계정이나 서버 기록을 삭제하려면 기존 가입 이메일과 삭제하려는 범위(계정 전체 또는 특정 기록)를 적어 아래 주소로 요청해 주세요. 요청은 본인과 대상 기록을 확인한 뒤 처리하며, 다른 가족 구성원이 작성한 기록은 별도로 확인합니다. 비밀번호나 사진 파일은 보내지 마세요.
