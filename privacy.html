개인정보처리방침

가족일정(운영: ShinDI)은 로그인 없이 쓸 수 있습니다. 아래 자동 백업 안내는 1.3.4 이상에서 해당 기능을 사용하는 경우에만 적용됩니다.

이 기기에 저장하는 기록

가족원 이름, 일정·장소·담당자·연락처 메모, 할 일, 지출 기록, 가족일정과 체크리스트, 일기·댓글·반응·첨부 사진을 기록하고 볼 수 있도록 기기에 저장합니다. 결제 메뉴는 지출을 기록하는 기능이며 실제 결제를 실행하지 않습니다.

이전 공유 기록을 보관하는 경우

이전 버전에서 가족 공유를 사용했다면 기존 계정으로 로그인해 서버에 남아 있는 일정·일기·사진을 확인할 수 있습니다. 1.3.3에서는 읽기 전용으로 보관하며, 1.3.4 이상에서는 기기로 가져온 사본을 원래 메뉴에서 수정할 수 있습니다. 이전 서버 원본은 읽기만 하며 변경하지 않습니다. 계정 확인에 이메일, 사용자 식별자와 로그인 세션을 사용합니다. 계정 인증과 기존 기록 조회에는 Supabase의 인증·데이터베이스·비공개 사진 저장소를 사용하며, 연결은 HTTPS로 이루어집니다.

새 가족 초대나 실시간 가족 공유는 제공하지 않습니다. 1.3.3에는 자동 클라우드 백업이 없으며, 새 기록과 첨부 사진은 서버에 업로드되지 않습니다.

자동 백업을 켜는 경우 (1.3.4 이상)

설정 → 계정 및 백업에서 기존 계정으로 로그인하고 동의하면, 기기의 일정·할 일·지출 기록·일기·사진과 기록에 입력한 이름·연락처·메모를 해당 계정에서 복원할 수 있도록 백업합니다. 백업 시각과 백업 식별 정보도 함께 보관합니다. 동의하지 않으면 자동 백업을 하지 않습니다.

백업은 HTTPS를 통해 Supabase의 비공개 데이터베이스에 전송하며, 로그인한 계정에 연결된 백업만 앱에서 접근할 수 있습니다. 사진은 일부 형식의 백업용 사본만 압축하며, 기기의 원본은 바꾸지 않습니다.

가장 최근에 성공한 백업 한 개를 다음 성공 백업으로 교체되거나 사용자가 삭제할 때까지 보관합니다. 중단된 업로드는 자동으로 정리합니다. 자동 백업을 끄면 새 백업을 만들지 않지만, 기존 서버 백업은 별도로 삭제해야 합니다.

주간일정을 보내는 경우 (1.3.5 이상)

로그인 없이 선택한 일정의 요일·시간·제목과 직접 입력한 전달 메모를 텍스트 또는 일정표 이미지로 만들 수 있습니다. 앱 설치 링크는 선택 사항입니다. 공유를 누르면 선택한 카카오톡 등 외부 앱으로 내용이 전달됩니다. 미리보기를 만들거나 공유하는 과정에서 가족일정 서버에 별도 사본을 보내지 않습니다.

Android 이미지 공유용 임시 파일은 앱 캐시에 저장됩니다. 이후 새 이미지 공유를 준비할 때 오래된 임시 파일을 정리하며, 직접 저장한 이미지에는 이 정리가 적용되지 않습니다. 외부 앱과 받는 사람이 보관하는 사본은 가족일정에서 회수하거나 지울 수 없습니다.

1.3.6 이상에서 카카오 카드 보내기를 선택하면, 카카오톡 공유 카드를 만들기 위해 일정의 요일·시간·제목과 전달 메모를 Kakao SDK로 카카오에 전송합니다. 가족일정 계정 정보, 연락처 칸, 일기, 사진은 카드로 보내지 않습니다. 제목이나 메모에 직접 적은 내용은 포함되므로 보내기 전에 확인해 주세요. 카카오 카드를 쓰지 않아도 텍스트나 일정표 이미지로 공유할 수 있습니다.

카카오 서비스에서 처리하는 정보에 대해서는 카카오 개인정보처리방침을 확인해 주세요.

보관 및 삭제

기기 기록은 직접 삭제하거나 앱 데이터를 지울 때까지 기기에 남습니다. 기기를 초기화하거나 바꾸기 전에 필요한 원본을 따로 보관해 주세요. 기기 데이터를 지워도 기존 계정과 이전 서버 기록은 삭제되지 않습니다. 각 데이터의 삭제 방법은 데이터 삭제 안내에서 확인할 수 있습니다.
