앱: 그냥쉴게요 (dev.takearest.app)
운영자: 신동인
문의: cosmology@daum.net

기기에 저장하는 정보와 목적

휴식 시작·종료 시각, 기록일과 시작 시간대, 실제 재생을 관찰하고 저장한 시간, 선택한 소리 종류, 스티커 그림·문구·날짜, 소리·타이머·화면 설정을 앱 전용 내부 공간에 저장합니다. 휴식 기록 표시, 스티커 제공, 선택한 설정 유지, 사용자가 요청한 백업과 복원에 사용합니다. 실제 수면 시간이나 건강 상태를 측정하지 않습니다.

수집과 외부 전송

앱의 기록과 설정을 운영자나 개발자 서버로 전송하지 않습니다. 계정, 광고, 이용 분석 도구, 자동 오류 보고, 자동 업로드와 클라우드 동기화를 제공하지 않습니다. 소리 파일은 앱에 포함되어 있으며 인터넷 없이 재생합니다. 위치·연락처·마이크 녹음 권한을 요청하지 않습니다.

보관과 삭제

내부 기록은 사용자가 삭제할 때까지 기기에 보관합니다. 설정의 ‘모든 기록 삭제’는 휴식 기록과 스티커, 복원 되돌리기용 내부 사본을 삭제하며 화면·소리 등 선호 설정은 유지합니다. Android 앱 데이터 삭제나 앱 삭제는 내부 기록과 설정을 삭제합니다. Android 자동 클라우드 백업과 자동 기기 이전 복원은 사용하지 않습니다.

사용자가 직접 내보내고 복원하는 파일

‘기록 내보내기’로 직접 선택한 위치에 휴식 기록과 스티커 파일을 저장할 수 있습니다. 백업 파일에는 날짜·시간·소리 종류·스티커 문구 등이 포함됩니다. 파일은 암호화되지 않은 JSON입니다. 체크섬은 파일 손상을 확인하는 장치이며 암호화가 아닙니다. 외부에 내보낸 파일은 앱 삭제 또는 내부 기록 삭제 후에도 남을 수 있으므로 해당 저장 위치에서 직접 삭제해야 합니다.

Android 파일 선택기에서 클라우드 공급자의 위치를 선택하면 파일 보관·동기화·전송·삭제는 해당 공급자의 기능과 개인정보처리방침을 따릅니다. 앱은 선택한 파일 위치만 읽거나 쓰며 자동으로 외부 파일을 관리하지 않습니다. 복원은 직접 선택한 파일을 검사하고 사용자가 승인한 후 현재 기록을 교체합니다. 자동 복원은 제공하지 않습니다.

권한과 외부 링크

화면을 꺼도 소리를 재생할 수 있도록 미디어 재생용 포그라운드 서비스, 시스템 미디어 알림 및 깨우기 잠금 기능을 사용합니다. 기록 파일은 Android 파일 선택기로 사용자가 지정한 위치에 접근합니다. 외부 출처 사이트 또는 이메일 앱을 직접 여는 경우 해당 서비스의 정책이 적용됩니다.

문의 및 방침 변경

문의 이메일로 연락하면 이메일 주소와 문의 내용이 운영자에게 전달됩니다. 이는 앱이 자동 수집하는 데이터가 아니며 문의 응대 목적으로만 사용합니다. 문의는 cosmology@daum.net으로 보내실 수 있습니다. 기능 또는 데이터 처리 방식이 변경되면 이 방침을 갱신하고 변경일과 내용을 안내합니다.
